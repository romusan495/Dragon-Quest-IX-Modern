Dragon Quest IX Modern v41: the project's new name, and the skill points table in widescreen.

**The project is now called Dragon Quest IX Modern**, and its page is https://github.com/romusan495/Dragon-Quest-IX-Modern. The old address still leads there, and the game's update check now uses the new one.

**What's new since v40**
- **Skill points in widescreen**: when you allocate skill points (after a battle or from the menu), the allocation menu stays whole in the middle and the skill's table sits small in the bottom right corner, instead of popping up over the menu. In the character's stats, the table sits beside the stats panel.
- The README is rewritten: a French description with an English part, the new Discord, what has been done so far, and credits to Romuald and TitanFr199 (Tsu).

**How to install**: download *Source code (zip)* below, unzip it and double-click `Install Dragon Quest IX.bat`, then choose your own ROM (USA or European). **Already on v31.x or later?** The game offers the update when it starts (or Help > Check for updates): your saves and settings are kept.

**Not included, on purpose**: no ROM, no game executable and no data from the game. Everything is built on your PC from the ROM you own.

**Playing with friends**: everyone needs the same version, so all of you update to v41.
