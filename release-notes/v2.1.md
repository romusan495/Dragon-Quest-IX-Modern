Dragon Quest IX Modern v2.1: the new character creation fixed in English, Italian and German.

**Fixed since v2.0**
- Character creation in English: the new wide-screen layout and the pop-up with the choices (Male / Female...) show again. Only the DS's top screen was shown before.
- Character creation in Italian: the step names and the choices are shown whole (they lost their first letter or showed a colon), and long names no longer overlap.
- Character creation in German: Ja / Nein are shown whole at the last question.

**How to install**: download *Source code (zip)* below, unzip it and double-click `Install Dragon Quest IX.bat`, then choose your own ROM (USA or European). Or install it from RecompLauncher. **Already installed?** The game offers the update when it starts (or Help > Check for updates): your saves and settings are kept.

**Not included, on purpose**: no ROM, no game executable and no data from any game. Everything is built on your PC from the ROMs you own.

**Playing with friends**: everyone needs the same version, so all of you update to v2.1.
